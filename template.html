Chaosbackend

This is a backend meant to be used with varnish to test different scenarios.

Faults are query parameters. They work on any path and can be combined.
,pct makes a fault happen only that percent of the time.

/page?status=404&sleep=5000
status and sleep (ms): returns a 404 after 5 seconds
/page?status=503,50
Returns a 503 half of the time, otherwise 200
/page?sleep=1000,500,30
Waits 1 second, plus up to 0.5 seconds extra 30% of the time
/page?sleep=1000&sleepBetweenBytes=100
Waits 1 second, then sends the body one byte every 0.1 seconds
/page?reset=1,20
Closes the connection without a response 20% of the time. Plain reset always does
/page?bytes=10000&truncate
Promises 10000 bytes, sends half, then closes the connection. truncate=N cuts after N bytes
/page?bytes=1048576
Returns a 1 MiB body. Add chunked to drop the Content-Length
/page?header=Cache-Control:max-age=60
Adds response headers. Can be repeated
/page?echo
Shows the request as the backend received it
/page?status=503,10&sleep=200,800&reset=1,2&truncate=1,5&bytes=20000
All together: a flaky origin
/health
Health check. Use /health/down, /health/up or /health/toggle to change it for this port
/error · /reset
Aliases: status defaults to 500, and reset is on by default
